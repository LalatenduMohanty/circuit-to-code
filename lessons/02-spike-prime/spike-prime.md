# LEGO SPIKE Prime (optional)

**Ages:** about 9–14\
**Optional:** Skip this module if you do not have a SPIKE Prime set. The core path goes
from [Scratch](../01-scratch/scratch-programming.md) straight to
[Beginner Circuits](../03-circuits/beginner.md).

**Goal:** Use the same block-coding ideas from Scratch on a real robot — without
rewriting LEGO’s lesson library here.

______________________________________________________________________

## Why try SPIKE after Scratch?

Scratch teaches loops, events, and “when X happens.” SPIKE Prime uses **Word blocks**
(Scratch-like) to drive motors and read sensors on a hub. If you care about
[First Lego League](https://www.firstlegoleague.org/) or already own the kit, this is a
fun side path. It is **not** required before circuits or the micro:bit.

______________________________________________________________________

## What you need

- [LEGO Education SPIKE Prime set](https://education.lego.com/en-us/products/lego-education-spike-prime-set/45678/)
- The SPIKE App (or browser support where available) via
  [spike.legoeducation.com](https://spike.legoeducation.com/)
- A charged hub and a flat space to test a simple driving base

______________________________________________________________________

## How to learn (use official lessons)

LEGO already publishes step-by-step units. Use those instead of inventing a second
curriculum here:

1. Open [spike.legoeducation.com](https://spike.legoeducation.com/) or the SPIKE App.
2. Start with beginner / Getting Started units.
3. Code along in **Word blocks**.
4. When a unit feels easy, remix it — change speeds, distances, or sensor reactions the
   way you remixed Scratch projects.

Python on SPIKE exists later; stay with Word blocks for this outline.

______________________________________________________________________

## Learning outline (checklist)

Before you leave this optional module, you should be able to:

- Connect the hub and run a downloaded program
- Drive and turn a simple robot with Word blocks
- Use at least one sensor (color, distance, or force) to change behavior
- Use loops and conditionals the same way you did in Scratch
- Complete several official beginner units in the SPIKE App

______________________________________________________________________

## Scratch → SPIKE reminder

| Scratch idea      | On SPIKE (Word blocks)     |
| ----------------- | -------------------------- |
| `forever` / loops | Repeat / forever loops     |
| `if` / wait until | Wait until / if conditions |
| Events (`when …`) | Events and sensor triggers |
| Sprite on screen  | Robot (motors + sensors)   |
