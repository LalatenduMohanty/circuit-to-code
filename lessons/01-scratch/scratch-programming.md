# Learning Scratch Programming

**Ages:** about 8–16 (younger with help)

**Goal:** Learn block coding by watching, remixing, and building games — the same
thinking you will reuse later on circuits and the micro:bit.

Scratch is a free, visual language from MIT. You snap colorful blocks instead of typing
code, so you can focus on ideas: loops, decisions, variables, and how a program flows.

______________________________________________________________________

## Why learn Scratch?

### For First Lego League and Spike Prime

The
[First Lego League Challenge (FLLC)](https://docs.google.com/document/d/1KZCcFFvkesUS_xx5VvvFtq8g9-icSPOr_dmMz-NSEiI/edit?tab=t.0#heading=h.ljtrygnsr3tf)
uses the
[LEGO Education SPIKE Prime set](https://education.lego.com/en-us/products/lego-education-spike-prime-set/45678/).
Teams can code missions with Scratch-style blocks or with Python. For many learners ages
9–14, Scratch (or Scratch-like blocks) is the friendliest way to start.

In a typical 12-week FLLC season (about 2–3 hours per week), coding often takes roughly
30–40% of the time. The rest goes to building, testing, and the innovation project. The
innovation project (a larger science-expo style challenge) can contribute nearly half of
the points toward winning.

### For parents

Scratch is a block-based language designed for kids (often ages 8–16, though younger and
older learners use it too). It is visual — drag and drop blocks instead of typing — so
it is a gentle entry into programming.

**Why it is worth considering**

- **Problem-solving:** Kids break ideas into steps (a game, a story, an animation).
  Research such as work in the *Journal of Educational Computing Research* (2020) links
  Scratch use with gains in computational thinking.
- **Creativity:** Stories, games, and art matter more than memorizing syntax. Many kids
  stay motivated designing their own versions of games they love.
- **A stepping stone:** Scratch is not Python or JavaScript, but it builds habits you
  reuse in text languages and in tools like MakeCode on the micro:bit. Early STEM
  exposure can open doors; the U.S. Bureau of Labor Statistics has projected strong
  growth in tech jobs.
- **Low barrier, high fun:** Blocks snap together, the editor is free at
  [scratch.mit.edu](https://scratch.mit.edu/), and a large community shares projects. A
  2022 Code.org survey found visual tools like Scratch help keep learners engaged longer
  than text-only coding for many beginners.

**It is not required for every child**

- **Not essential:** If a child thrives in sports, music, or another craft, forcing
  Scratch can backfire. Passion drives learning; coding is one path among many.
- **Limited depth:** Scratch will not teach advanced algorithms or data structures by
  itself. It is a starter, not a full career curriculum.
- **Screen time:** Balance coding with outdoor play and offline making.

## Getting started

1. Create an account at [scratch.mit.edu](https://scratch.mit.edu/).
2. Open the **Tutorials** section (top right once you are signed in) and try one short
   built-in tutorial so the editor feels familiar.
3. Work through the video path below. Watch a clip, then **code along** in Scratch.
4. When you finish a project, explore shared projects on Scratch, **remix** one you
   like, and change something small — that is how you learn to read other people’s code.

**How to use this guide**

- Stay with **Beginner projects** until a few feel easy.
- Move to **Intermediate**, then **Advanced**, when you want harder challenges.
- Items without a video link are project ideas you can invent yourself (or search for on
  Scratch / YouTube).
